1. Mathematical Language and Symbols

Mathematical language uses words, numbers, and symbols to communicate mathematical ideas clearly.

Examples:

+ = addition
− = subtraction
× = multiplication
÷ = division
= = equal to
≠ = not equal to
< = less than
> = greater than
≤ = less than or equal to
≥ = greater than or equal to

2. Mathematical Expression

A mathematical expression is a combination of numbers, variables, and mathematical symbols.

Examples:

5 + 3
10 − 4
2 × 6
x + 5
3x + 2

Example: In 3x + 2, 3 is the coefficient, x is the variable, and 2 is the constant.

3. Set

A set is a collection of well-defined objects or elements.

Example:

A = {1, 2, 3, 4, 5}

The numbers 1, 2, 3, 4, and 5 are the elements of set A.

4. Set-Builder Notation

Set-builder notation describes a set by stating the rule or condition that its elements must follow.

Example:

A = {x | x is a whole number less than 5}

Therefore:
A = {0, 1, 2, 3, 4}

The symbol | means "such that."

5. Different Types of Sets

  • Empty Set – a set with no elements.
  • Singleton Set – a set with only one element.
  • Finite Set – a set with a specific number of elements.
  • Infinite Set – a set that continues without end.
  • Equal Sets – sets that contain exactly the same elements.
  • Equivalent Sets – sets that have the same number of elements.
  • Subset – a set whose elements are all contained in another set.
  • Universal Set – the set containing all elements being considered.
Examples:

Empty Set: ∅
Singleton: {5}
Finite: {1, 2, 3}
Infinite: {1, 2, 3, 4, ...}

6. Venn Diagram

A Venn diagram uses circles to show relationships between sets.

Set A
Set B
Intersection: The overlapping part represents elements that belong to both sets.

Union: All elements found in either set or both sets.

7. Reasoning

Reasoning is the process of using facts, observations, and logic to reach a conclusion.

Deductive Reasoning

Deductive reasoning starts with a general rule and applies it to a specific situation.

Example:

All humans need oxygen.
Ana is a human.
Therefore, Ana needs oxygen.

Inductive Reasoning

Inductive reasoning starts with specific observations and uses them to form a general conclusion.

Example:

The sun rose today.
The sun rose yesterday.
The sun has risen every day observed.
Therefore, the sun will probably rise tomorrow.

Quick Difference

Deductive Inductive
General → Specific Specific → General
Uses rules or facts Uses observations or patterns
Conclusion follows logically Conclusion is a prediction/generalization
